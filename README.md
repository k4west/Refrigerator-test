# Refrigerator-test

오프라인에서 실행 가능한 **냉장고 시뮬레이션 웹페이지**입니다.

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 실행됩니다.

또는 간단한 로컬 서버를 사용하려면:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 주요 기능

- 사이드바 음식 6종(사과, 콜라, 식빵, 야채, 고기, 우유) 추가
- 냉장고 내부에서 음식 제거
- 현재 재료 기반 레시피 추천(정적 데이터)
- 중복 추가 방지
- 오프라인 단독 동작 (외부 API/서버 의존 없음)
